## 🚀 Proyectos Destacados

### 📚 Sistema de Gestión de Colecciones Literarias
*Un sistema integral de backend y frontend diseñado para gestionar inventarios complejos de libros y mangas, aplicando principios de arquitectura limpia y desarrollo guiado por IA.*

* **Características Clave:**
    * Arquitectura basada en **Microservicios** desarrollados en **C# (.NET)**.
    * Interfaz de usuario responsiva construida con **React** y **TypeScript**.
    * Infraestructura completamente contenerizada mediante **Docker** para despliegues rápidos.
    * Uso de **Kiro** para la generación de especificaciones de requerimientos (`requirements.md`) y **Antigravity** para la automatización de pruebas de interfaz en entornos Fedora.
* **Technical Writing:** Documentación detallada de arquitectura, diagramas de flujo de datos y documentación de endpoints de la API redactados completamente en Markdown.
